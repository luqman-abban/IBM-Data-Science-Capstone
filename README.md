# IBM-Data-Science-Capstone
End-to-end SpaceX Falcon 9 Data Science Capstone Project covering data collection, web scraping, SQL analysis, exploratory data analysis, interactive visual analytics, feature engineering, and machine learning for predicting Falcon 9 first-stage landing success. Built using Python, SQL, Pandas, Matplotlib, Seaborn, Plotly Dash, and Scikit-learn.
